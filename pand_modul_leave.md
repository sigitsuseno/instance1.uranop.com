# LEAVE

## Menu Leave/Pengelolaan Cuti

Menu Pengelolaan Cuti

- Submenu : Generate cuti Tahunan.
- Submenu : Pengajuan Cuti
- Submenu : Pembatalan Cuti
- Submenu : Saldo Cuti.
- Submenu : Rekap Cuti

## Detail

1. Generate cuti tahunan
    - di halaman ini ada proses pembuatan periode cuti, (periode cuti ini tanggal awal dan akhir di tentukan oleh hrd)
    - proses generate per periode berdasarkan pengaturan cuti
2. Pengajuan cuti.
    - halaman yang bersisi daftar pengajuan berdasarkan periode cuti
    - ada tombol pengajuan yang membuka modal untuk pengajuan cuti
    - ada tombol approve yang akan memunculkan checkbox di daftar pengajuan untuk bulk approve dan single approve.
    - approval bisa dilakukan oleh user superadmin dan hr
    - ada tombol export daftar pengajuan cuti, (format excel, pdf)
3. Pembatalan Cuti.
    - halaman yang bersisi daftar pembatalan berdasarkan periode cuti
    - ada tombol pembatalan yang membuka modal untuk pembatalan cuti
    - ada tombol approve yang akan memunculkan checkbox di daftar pembatalan untuk bulk approve dan single approve.
    - approval bisa dilakukan oleh user superadmin dan hr
    - ada tombol export daftar pembatalan cuti, (format excel, pdf)
4. Saldo Cuti.
    - halaman yang bersisi daftar saldo cuti tahunan berdasarkan periode cuti
    - ada tombol export saldo cuti, (format excel, pdf)
5. Rekap cuti.
    - halaman rekapitulasi saldo cuti tahunan.
    - fungsi untuk reset saldo cuti.
