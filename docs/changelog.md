# Changelog

## 2026-10-09
- [New] Input Data Lama: halaman baru di menu Kehadiran (rute `/admin/attendance/input-data-lama`, `requiresSuperadmin`) untuk mengisi kehadiran periode lama dari berkas Excel `absen_core` — dropdown periode, pemilih berkas dari File Manager, pratinjau tanpa menulis, lalu proses simpan
- [New] Input Data Lama: berkas sumber **tidak diunggah** lewat halaman ini, melainkan dipilih dari disk privat File Manager. Path divalidasi lewat `FileManagerPathGuard` (tolak traversal, symlink, dan path absolut), wajib berkas spreadsheet (.xlsx/.xls/.xlsm/.xlsb/.ods) maksimal 20 MB. Karena itu rutenya dibatasi `role:superadmin`, sama seperti modul File Manager
- [New] Input Data Lama: `LegacyAttendanceMatrixImport` membaca matrix (baris 1 tanggal, baris 2 nama hari, kolom 1 = NIP, kolom ganjil = kode status, kolom genap = jam lembur hari yang sama); hanya sheet pertama yang dibaca karena berkas bisa punya sheet lain dengan layout berbeda
- [New] Input Data Lama: `LegacyAttendanceInputService` memetakan kode ke tiga tabel — `att_prepares` (`H`→hadir, `CSF`→hadir tanpa jam, `L`→hadir + `lm` 480 menit, `OFF`→off, `ALFA`/`OUT`/`-`/sel kosong→absent, `CUTI`→ct, `SAKIT`→skt, `IZIN`→itm, `CTM`→ctm, `CTH`→cth, `CTN`→cm, `CHJ`→ch, `CMD`→ckm), `leave_requests`, dan `att_consecutive_days` (1 baris per sel `CSF`)
- [New] Input Data Lama: `leave_requests` dibuat satu per rentang hari berurutan (status approved, saldo dipotong). Sebelum dibuat, tiap tanggal dicek dulu: bila sudah ditempati leave_request berstatus **approved**, hari itu dilewati sehingga rentang bisa terpecah — mencegah cuti dobel dan saldo terpotong dua kali. Status `pending`/`cancelled`/`rejected` tidak dianggap menempati tanggal
- [New] Input Data Lama: kolom genap jadi `overtime` (jam × 60) di hari kerja, atau `lm` bila Minggu/holiday; Minggu tanpa kode dengan jam lembur memakai jam tetap 08:00 dengan `check_out` = 08:00 + jam lembur
- [New] Input Data Lama: karyawan grup `GRP-JKT` yang tidak ada di berkas tetap dibuatkan record penuh periode dengan kolom jam/lembur kosong (`off` untuk Minggu/holiday, `absent` sisanya, `review_status` cek); jadwal & `check_in` diambil dari `sch_employee_shift_rosters`, dan proses ditolak bila roster periode belum ada
- [New] Input Data Lama: `LeaveRequestService::createApprovedForDate()` meresolusi `leave_period_id` dari tanggal transaksi — `approveAndPrintRequest()` memilih periode cuti aktif terbaru sehingga cuti lama bisa masuk ke periode yang salah
- [Fix] `LeaveRequestService::getOrCreateBalanceRecord()` menulis `transaction_type = 'initial'` yang bukan anggota enum `('increment','decrement')`; pada MySQL strict mode ini menggagalkan approve cuti saat saldo belum ada — diubah menjadi `increment`
- [New] File Manager: modul `app/Modules/FileManager` untuk mengelola berkas aplikasi — folder bertingkat (buat/ganti nama/hapus/pindah dengan breadcrumb), unggah multi-berkas, unduh, ganti nama, hapus, pratinjau gambar/PDF/teks/isi sheet Excel, serta pencarian dan filter jenis berkas
- [New] File Manager: berkas disimpan di disk privat `file_manager` (`storage/app/file-manager`) yang tidak dapat diakses lewat URL publik; seluruh akses lewat endpoint `api/v1/file-manager/*` dan terbatas untuk `superadmin`
- [New] File Manager: halaman `resources/js/Pages/Admin/FileManager/Index.vue` (rute `/admin/file-manager`, `meta.requiresSuperadmin`) dengan komponen `Breadcrumbs`, `FileGrid`, `UploadModal`, `PreviewModal`, `ExcelPreview`, dan `MoveModal`; unduhan memakai fetch + Blob karena endpoint butuh header Bearer
